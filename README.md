One broadsheet front page — **The World Today, Thursday 19 November 2026** — summarising the day's world news in a single 1024×1024 image: 22 stories across politics, markets, justice, climate, conflict and culture, from the first Trump–Xi–Putin trilateral summit in Shenzhen to the Anthropic IPO debut, the ICJ Rohingya ruling, GTA VI's launch and Cyclone Akvan. Every illustration is drawn programmatically with Pillow; every fact is sourced in [SOURCES.md](SOURCES.md).

## Run it

```sh
python main.py   # copies entry.png to /output/entry.png (or $MAKEFUN_OUTPUT_DIR)
```

To re-render the image from scratch: `python render.py` (requires Pillow; fonts bundled under `fonts/`, SIL OFL 1.1).
